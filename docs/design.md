# bnki 设计文档（v0.1，待确认）

> bnki：本地自用的卡片复习系统，复刻氢刻（qingk.com）的 UI 与功能，换掉它的复习调度。
> 状态：设计 + 原型阶段。**原型确认之前不写实现代码。**
> 原型：`prototype/index.html`，直接用浏览器打开即可（需要联网加载 markdown-it / KaTeX / highlight.js / turndown）；也可以 `python3 -m http.server 18421 -d prototype` 后访问 http://localhost:18421 。原型数据只存在浏览器 localStorage 里，底部条可以“重置示例数据”。

---

## 0. 背景与目标

### 0.1 为什么做

- 氢刻维护慢，小功能拖着不做。
- 复习调度是固定阶梯（见 §6.1）：新卡点“记住了”后 30 分钟就要复习，再过 12 小时又一次，而且完全不看逾期多久。
- 想要一个自己能随时改的本地版本。

### 0.2 约束（已确认）

| 项 | 结论 |
|---|---|
| 平台 | 只在电脑上用（桌面浏览器），不做移动端、不做触屏手势 |
| 数据 | 不迁移氢刻旧数据 |
| 内容格式 | **卡片必须支持 Markdown** |
| 挖空 | 最常用功能，编辑与复习体验要优先保证 |
| 联网 | 纯本地，单用户，无账号、无同步、无云端 |
| 范围 | MVP 先尽量还原原有功能；不需要的（学习小组、社区等）直接砍掉 |

## 2. 技术方案

### 2.1 形态

本地 Web 应用：一个 Node 进程同时提供 API 和打包好的前端，浏览器打开 `http://localhost:18420`。

- 不用 Electron/Tauri，MVP 少一层打包；以后想要独立窗口再套 Tauri。
- 端口段 **18420–18429**（已用 `lsof` 确认空闲）：主服务 18420，前端开发服务器 18421。写进 CLI 默认值、README 和 `.claude/launch.json`。

### 2.2 技术栈

| 层 | 选型 | 理由 |
|---|---|---|
| 前端 | React 18 + TypeScript + Vite | 生态全，编辑器库多 |
| 状态 | Zustand + TanStack Query | 轻 |
| 编辑器 | **Tiptap 2（ProseMirror）** + 自定义 Cloze mark | 所见即所得，输入规则原生支持，能精确序列化成 Markdown |
| Markdown 渲染 | markdown-it + 自定义插件（cloze、mark、katex、highlight.js） | 网格预览和学习页渲染快，不用实例化编辑器 |
| 公式 | KaTeX | |
| 代码高亮 | highlight.js（和原版一致） | |
| 后端 | Node 24 + Fastify | |
| 数据库 | SQLite（better-sqlite3），WAL 模式 | 单文件、好备份 |
| 调度 | **ts-fsrs**（FSRS-5/6） | 社区维护，就是 Anki 用的算法 |
| 拖拽 | dnd-kit | |
| 图表 | 手写 SVG（统计页只有两三张图） | |

## 3. 内容格式：Markdown + 挖空

### 3.1 原则

- **卡片内容存 Markdown 文本**，不存 Delta 或 HTML。好搜、好导出，以后换编辑器也不会锁死。
- 标准语法：CommonMark + GFM（表格、删除线、任务列表）。
- 原版有、但 Markdown 没有的样式（挖空、彩色马克笔、下划线、波浪线、文字颜色），用**最小扩展语法**表达，见下表。
- 编辑器和渲染器共用 `shared/markdown` 的规则，并加测试：解析 → 序列化 → 再解析，结果必须一致。

### 3.2 挖空语法

```markdown
TCP 三次握手的第二步是 {{SYN+ACK}}。
- 进程是 {{资源分配}} 的基本单位，线程是 {{CPU 调度}} 的基本单位
- 挖空里可以套格式：{{**volatile**}}、{{`HashMap`}}
```

| 规则 | 说明 |
|---|---|
| `{{内容}}` | 一个挖空。不能跨行，不能嵌套（和你的旧数据一致：没有跨行的空） |
| 挖空内部 | 可以有加粗、斜体、行内代码、马克笔、公式 |
| 代码块、行内代码里 | 不解析（你的旧数据里代码块中没有挖空） |
| 想写字面量 `{{` | 写成 `\{{` |
| 编号 | 渲染时按出现顺序自动编号 1..N，用于“显示下一个”。MVP 不做 Anki 那种 `c1/c2` 分组 |
| 选型理由 | 和 Anki 的 `{{c1::…}}` 相近、好记；不和 `==高亮==`、`[[链接]]` 冲突；在纯文本里也一眼能看出 |

**编辑器里的行为：**

- 选中文字后按 ⌘E（或 ⌘K，和原版一致），或点工具栏“挖空”按钮：加上或去掉挖空，显示为蓝色下划线。
- 没选中时按 ⌘E：插入一个空挖空并把光标放进去。原版此时什么都不做，这是一个小改进。
- 直接敲 `{{文字}}`：输入规则自动转成挖空。
- 光标在挖空里时，工具栏的“挖空”按钮呈激活态；再按 ⌘E 取消挖空。

**复习时的行为（还原原版）：**

- 挖空显示为等宽的蓝色下划线空白，宽度约等于答案长度。
- 点空白揭示，再点隐藏。V 揭示下一个；Shift+V 全部显示或全部隐藏。
- 右下角显示计数 `已揭示/总数`。
- 问答卡背面也可以有挖空。点“显示答案”**不会**自动揭示背面的空（原版行为）。

### 3.3 其他扩展语法

| 原版样式 | Markdown 写法 | 说明 |
|---|---|---|
| 马克笔（默认黄） | `==文字==` | 常见扩展（Obsidian、Typora 都支持） |
| 彩色马克笔 | `<mark data-c="red">文字</mark>` | 颜色：yellow / green / blue / red / purple |
| 下划线 | `<u>文字</u>` | |
| 波浪线 | `<mark data-s="wavy">文字</mark>` | 可再加 `data-c` |
| 马克笔下划线样式 | `<mark data-s="line">文字</mark>` | |
| 文字颜色 | `<span data-tc="red">文字</span>` | red / blue / green / grey |
| 字号（P1） | `<span data-fs="22">文字</span>` | 只允许 12 / 16 / 22 / 26 |
| 公式 | `$x^2$`、`$$…$$` | KaTeX |
| 图片 | `![](media/3f2a….png)` | 粘贴时上传到 `data/media`，按内容哈希命名，可去重 |
| 卡片链接（P1） | `[显示文字](bnki://card/<id>)` | 点击跳到那张卡 |

内联 HTML 只允许上表这几种标签和属性，渲染前用白名单清洗，其余一律当作纯文本。

### 3.4 编辑器设计

**默认是所见即所得**（和原版一样的手感），同时支持三种 Markdown 用法：

1. **输入规则**：行首敲 `# `、`- `、`1. `、`> `、` ``` `，行内敲 `**x**`、`*x*`、`` `x` ``、`==x==`、`{{x}}`，自动转换成对应格式。
2. **粘贴**：剪贴板是 Markdown 纯文本时，自动解析成格式；粘贴图片时上传；粘贴网页 HTML 时清洗成支持的格式。
3. **源码模式**：每个字段右上角有 `M↓` 按钮，切到 Markdown 源码（等宽字体），再切回来。适合批量改、查格式问题。

**工具栏**（还原原版顺序，挖空放在显眼位置）：

`T▾（正文/H1/H2/H3）｜ 马克笔▾ ｜ B I U ｜ 挖空 ⌘E ｜ 清除格式 ｜ 链接 ｜ 撤销 恢复 ｜ 无序列表 有序列表 引用 代码块 公式 ｜ 图片 ｜ M↓`

- 马克笔下拉：5 个颜色 × 3 种样式（马克笔、下划线、波浪线）+ 4 种文字颜色。原版是 15 色 + 6 种文字色，你的旧数据里真正用到的颜色很少，MVP 先精简。
- 每个字段底部：图片按钮。录音、附件放 P2。
- **问答卡**：问题 → “+ 提示”（点开才出现）→ 答案。提示框占位文字：“可填写口诀、速记、关键词或易错提醒，学习时先于答案显示”。
- **主题卡**（P1）：标题 + 纯文本内容；切换到主题卡时提示“样式和图片会被清除”。

## 4. 数据模型（SQLite）

```sql
-- 分类（文件夹）
CREATE TABLE folders (
  id          TEXT PRIMARY KEY,
  name        TEXT NOT NULL,
  position    REAL NOT NULL,
  created_at  INTEGER NOT NULL
);

-- 卡片集
CREATE TABLE decks (
  id            TEXT PRIMARY KEY,
  title         TEXT NOT NULL,
  description   TEXT NOT NULL DEFAULT '',
  folder_id     TEXT REFERENCES folders(id),
  cover         TEXT,                 -- media 路径或 URL
  pinned_at     INTEGER,              -- 置顶
  created_at    INTEGER NOT NULL,
  updated_at    INTEGER NOT NULL,     -- 编辑时间
  opened_at     INTEGER,              -- 最近使用
  studied_at    INTEGER,              -- 学习时间
  deleted_at    INTEGER,              -- 回收站
  study_cfg     TEXT NOT NULL DEFAULT '{}',  -- 学习设置（§5.2）
  display_cfg   TEXT NOT NULL DEFAULT '{}'   -- 布局、显示选项
);

-- 目录和卡片放在同一个有序列表里，和原版的 children 一致
CREATE TABLE items (
  id          TEXT PRIMARY KEY,
  deck_id     TEXT NOT NULL REFERENCES decks(id),
  kind        TEXT NOT NULL CHECK (kind IN ('section','card')),
  position    REAL NOT NULL,          -- 小数排序，拖拽只改一行
  -- section 字段
  level       INTEGER,                -- 1..5
  title       TEXT,
  collapsed   INTEGER DEFAULT 0,
  -- card 字段
  card_type   TEXT,                   -- note | qa | topic
  front       TEXT,                   -- Markdown
  hint        TEXT,
  back        TEXT,
  color       TEXT DEFAULT 'default', -- 10 色之一
  created_at  INTEGER NOT NULL,
  updated_at  INTEGER NOT NULL,
  deleted_at  INTEGER
);
CREATE INDEX items_deck_pos ON items(deck_id, position);

-- FSRS 记忆状态（一张卡一行）
CREATE TABLE card_states (
  card_id        TEXT PRIMARY KEY REFERENCES items(id),
  state          INTEGER NOT NULL,   -- 0 New, 1 Learning, 2 Review, 3 Relearning
  due            INTEGER,            -- 下次复习时间（ms）
  stability      REAL,
  difficulty     REAL,
  elapsed_days   REAL,
  scheduled_days REAL,
  learning_steps INTEGER DEFAULT 0,
  reps           INTEGER DEFAULT 0,
  lapses         INTEGER DEFAULT 0,
  last_review    INTEGER,
  mastered       INTEGER DEFAULT 0   -- “完成学习”
);
CREATE INDEX card_states_due ON card_states(due);

-- 复习日志：统计、日历、以后用自己的数据训练 FSRS 参数
CREATE TABLE review_logs (
  id          INTEGER PRIMARY KEY,
  card_id     TEXT NOT NULL,
  deck_id     TEXT NOT NULL,
  kind        TEXT NOT NULL,   -- grade | manual | master | reset
  rating      INTEGER,         -- 1 忘记了 2 模糊 3 记住了（4 简单，预留）
  state       INTEGER,
  due         INTEGER,
  stability   REAL,
  difficulty  REAL,
  elapsed_days REAL,
  scheduled_days REAL,
  reviewed_at INTEGER NOT NULL,
  duration_ms INTEGER
);
CREATE INDEX review_logs_time ON review_logs(reviewed_at);

-- 编辑日志：给“学习与编辑曲线”用
CREATE TABLE edit_logs (
  id        INTEGER PRIMARY KEY,
  card_id   TEXT NOT NULL,
  action    TEXT NOT NULL,     -- create | update | delete
  at        INTEGER NOT NULL
);

CREATE TABLE media (
  hash       TEXT PRIMARY KEY,
  path       TEXT NOT NULL,
  mime       TEXT NOT NULL,
  size       INTEGER NOT NULL,
  created_at INTEGER NOT NULL
);

CREATE TABLE settings (key TEXT PRIMARY KEY, value TEXT NOT NULL);
```

- **软删除**：卡片和卡片集都先打 `deleted_at`，回收站里“彻底删除”才物理删除。卡片的删除可以撤销（toast 里的“撤销”）。
- **全文搜索**：P1 加 SQLite FTS5 虚拟表（`front`、`hint`、`back` 去掉 Markdown 标记后的文本）。
- **备份**：设置里“立即备份”调用 SQLite `VACUUM INTO`，同时打包 `media/`；启动时每天自动备份一次，保留最近 14 份。

## 5. 学习流程

### 5.1 出卡队列

一次学习打开时，按学习设置生成队列：

1. **筛选**：学习目录（多选）、卡片颜色（多选），排除已掌握的卡片。
2. **学习内容**：
   - 系统推荐：到期卡片 + 新卡。分别受每日复习上限、每日新学上限约束，扣掉今天已学的数量。
   - 仅未学习：新卡。
   - 仅复习：到期卡片。
   - 全部卡片：按顺序浏览全部，也可以评分。
3. **卡片顺序**：
   - 按顺序：卡片集里的顺序。
   - 到期优先：逾期最久、可提取率最低的排在前面。
   - 随机。
   - 系统推荐模式下，先排复习卡，再穿插新卡。
4. **出题方向**（只对问答卡）：问题优先、答案优先（正反对调）、随机。
5. **本轮重练**：评“忘记了”的卡，在本轮里排到 3–5 张之后再出现一次。toast：“已加入本轮稍后再练一次”。本轮再次出现时的评分**不再改变 FSRS 状态**，只是练习，避免同一天重复惩罚（可在设置里关掉）。

“到期”的判定：按天模式下，`due` 在今天学习日结束（次日 04:00）之前都算到期；灵活模式下是 `due <= now`。

### 5.2 学习设置（每个卡片集一份，存 `decks.study_cfg`）

```json
{
  "content": "recommend | new | review | all",
  "colors": [],
  "sections": [],
  "order": "sequential | due_first | random",
  "direction": "front | back | random",
  "clickBlankRevealNext": true,
  "plan": {
    "mode": "flexible | daily | sprint",
    "examDate": null,
    "newPerDay": 20,
    "reviewPerDay": 100
  }
}
```

### 5.3 学习页交互

- 顶部：`系统推荐 (3/24)`、朗读、编辑（E）、⋮。
- 卡片区：卡片颜色作为背景（和网格一致的渐变）；文字大小、卡片大小来自 ⋮ 菜单，按卡片集记住。
- 已学过的卡片，顶部显示状态行：`需复习 · 逾期 3 天 ｜ 已复习 5 次 ｜ 上次 10月18日`。
- 底部评分键：`忘记了 / 模糊 / 记住了`，每个键下方是 FSRS 预测的间隔（如“本轮稍后”“1天”“3天”）。⋯ 打开：
  - 自定义下次复习：15 分钟、1 小时、6 小时、明天、3 天、7 天、14 天、30 天、3 个月、N 天、选日期。
  - 完成学习（标记已掌握，不再出现）。
  - 彻底忘记（重置为新卡）。
- 问答卡：评分键在显示答案之后才可用（原版是这样）。笔记卡：评分键一直可用。
- 结束页：学习完成；本次学习 N 张、用时 X 分钟、忘记/模糊/记住各几张；按钮“完成”“再学一组”（如果还有到期卡）。

## 6. 复习调度

### 6.1 原版算法（从源码读出来的，作为对照）

- 灵活模式阶梯：30 分钟、12 小时、1 天、2 天、3 天、5 天、8 天、15 天、30 天、60 天、120 天、240 天、360 天。
- 记住了：进一档。模糊：下一档 × 0.6。忘记了：10 分钟后再看，档位退 2 档（每天最多退一次）。
- 按天、冲刺模式：记住了用 3、7、15、30、60、90、120、180、240、360 天。冲刺模式每次间隔不超过“距考试天数 / 3”。
- 问题：
  - 不看逾期时长：逾期 5.6 个月的卡，点记住了也只给 12 小时。
  - 每张卡难度不同，但只有一条固定阶梯。
  - 新卡第一次复习就在 30 分钟后。

### 6.2 bnki：FSRS

用 ts-fsrs，三个按键映射为 FSRS 评分：

| 按键 | FSRS Rating | 含义 |
|---|---|---|
| 忘记了 | Again (1) | 没想起来 |
| 模糊 | Hard (2) | 想起来了但很吃力或不确定 |
| 记住了 | Good (3) | 正常想起 |
| （可选）很简单 | Easy (4) | 设置里打开后出现第 4 个键，默认关闭 |

用 FSRS 默认参数时，大致的间隔（目标记忆保持率 0.90，按天模式）：

| 场景 | 忘记了 | 模糊 | 记住了 |
|---|---|---|---|
| 新卡第一次 | 本轮稍后，明天 | 明天 | 3 天 |
| 第二次（3 天后，记住了） | 本轮稍后，约 1 天 | 约 5 天 | 约 11 天 |
| 第三次（11 天后，记住了） | 本轮稍后，约 2 天 | 约 16 天 | 约 1.2 个月 |
| 逾期很久的卡 | FSRS 会按实际间隔算可提取率，记住了给的间隔会**更长**，不会再出现“逾期 5 个月只给 12 小时” | | |

（原型里的数值是用 FSRS-5 公式实时算出来的，可以点着看。“系统设置 → 记忆算法”会显示新卡一直点“记住了”的整条间隔链，调目标记忆保持率时实时变化。）

### 6.3 三种复习模式在 FSRS 下的含义

| 模式 | bnki 中的含义 |
|---|---|
| **按天**（默认） | 不设当天短间隔。新卡评分后最早明天再见；到期按“学习日”（默认 04:00 换日）结算，当天到期的一次性出完 |
| **灵活** | 开启 FSRS 短期步长（学习步长默认 `10m`，重学步长 `10m`）。新卡评忘记了或模糊会在 10 分钟后再出现；评记住了直接毕业。步长可在设置里改 |
| **冲刺** | 设置考试日期。间隔 = min(FSRS 间隔, max(1 天, 距考试天数 / 3))，保证考前还能再见几次；过了考试日自动回到按天模式 |

另外的 FSRS 设置项（系统设置里，全局生效；每个卡片集可以覆盖模式和每日上限）：

- 目标记忆保持率：0.80–0.97，默认 0.90。越高复习越频繁。
- 最大间隔：默认 365 天（和原版上限一致），可改。
- 间隔随机抖动（fuzz）：默认开，避免同一天堆积。
- 参数优化：P2，用自己的 `review_logs` 训练 FSRS 参数（ts-fsrs 或 fsrs-rs 都能做）。

### 6.4 “完成学习”与“彻底忘记”

- **完成学习**：`mastered = 1`，退出所有队列，计入“已学”。在卡片 ⋯ 或学习页 ⋯ 里可以“恢复学习”。
- **彻底忘记**：状态回到 New，保留历史日志。
- **重新开始学习**（卡片集 ⋯ 菜单）：整个卡片集所有卡片重置为 New，二次确认“确认重置”。

### 6.5 进度口径

- 已学 = 有过评分或已掌握的卡；未学 = New 且未掌握。
- 待复习 = 到期且未掌握（口径见 §5.1）。
- 百分比 = 已学 / 总数。

## 7. 统计

- **学习日历**：一天有至少一次评分就算“学习了”。连续天数、最长连续记录（起止日期）、本月学习天数，月历上按当天评分量深浅着色。
- **数字**：今日学习卡片（去重卡片数）、累计学习卡片、卡片集数、卡片总数。
- **学习与编辑曲线**：每天的评分次数和新建/编辑卡片数，7/30/90 天切换。
- **P1**：未来 30 天到期预测柱状图；真实记忆保持率（按“记住了 + 模糊”占比统计，和目标保持率对比）。
